# CodePlay 🎮💻

CodePlay is a multiplayer programming learning platform designed to make coding fun, interactive, and game-based.
The platform helps students learn programming languages through quizzes, levels, real-time multiplayer battles, leaderboards, and engaging UI experiences.

## 🚀 Features

* 🎯 Programming quiz levels
* 👥 Real-time multiplayer gameplay
* 🏆 Leaderboard and score tracking
* 🎮 Create and join rooms with friends
* 👤 Avatar selection system
* 🔊 Sound effects for correct/wrong answers
* 📚 Multiple programming languages support

  * Python
  * Java
  * C++
  * More coming soon...
* 🌐 Responsive and attractive UI
* 🔐 Login and registration system
* ⚡ Real-time synchronization using Firebase

## 🛠️ Technologies Used

* HTML
* CSS
* Tailwind CSS
* JavaScript
* PHP
* MySQL
* Firebase Realtime Database

## 📌 Project Goal

The main goal of CodePlay is to transform traditional programming learning into an enjoyable gaming experience where students can practice coding concepts interactively and competitively.

## 🎮 How It Works

1. User creates an account or logs in
2. Player can create or join a room
3. Quiz levels are unlocked step-by-step
4. Players answer programming questions
5. Scores are updated in real time
6. Winners are displayed on leaderboard
